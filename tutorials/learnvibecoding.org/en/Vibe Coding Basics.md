# Vibe Coding Basics

Vibe coding means describing the software you want and letting an AI write it. Instead
of typing every line, you express intent:

> "Write a web page that shows a todo list with an add button."

The model turns that sentence into code. Your job is to guide it: choose the right
words, give examples, and check the result.

### Why tiny models?

Large models are powerful but need big servers. A tiny model like SmolLM2-360M is
small enough to run in your browser on WebGPU — it downloads once and then works
offline, privately, and for free. It makes mistakes more often than a large model, so
you learn to write prompts that are clear and specific.

### What you can build

Even a small model can draft:

- Small web pages and components
- JavaScript, Python, or shell snippets
- Data-processing logic
- Styling and layout ideas

The model is a starting point. You are the developer: you refine, test, and ship.
