# Building Your First App

Let's put it together. You are going to build a small, working app by prompt only.

### Step 1 — Describe the app

    Write a single HTML file with a counter. It shows a number and two buttons:
    plus and minus.

### Step 2 — Refine the design

    Make the buttons round and add a title "My Counter".

### Step 3 — Add behavior

    When the number reaches 10, change the background color to green.

### Step 4 — Save and test

Copy the generated code into a file named `index.html` and open it in your browser.
Make any fixes by asking follow-up prompts, then re-copy.

### Congratulations

You just vibe-coded your first app. The same loop — describe, generate, refine,
test — scales to real projects. As you practice, you will get faster at writing the
prompts that produce the code you want.
