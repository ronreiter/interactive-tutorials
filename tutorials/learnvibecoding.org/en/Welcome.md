# Welcome

Welcome to the LearnVibeCoding.org interactive tutorial!

Vibe coding is the art of building software by describing what you want in plain
language and letting an AI model write the code for you. In this tutorial, you will
learn how to write effective prompts, how to iterate on generated code, and how to
turn a simple idea into a working app.

Unlike a traditional compiler, every page here runs a real, tiny language model
(<strong>SmolLM2-360M</strong>) directly in your browser using WebGPU — no server, no
API keys. You can try each concept live as you read.

Just click on the chapter you wish to begin from, and follow the instructions. Good luck!
